# Kneuklid Romance Live Manager

**Beyond the Rainbow** のメンバー共有用ライブ進捗管理画面です。

## 現在の管理対象
- 会場・開催日
- チケット／VIP条件
- リハーサル
- 楽曲方針
- グッズ
- 公式LINE／告知
- デザイン素材
- 同期
- 担当者
- 議事録
- スケジュール（日付・時間・内容・場所・担当・状態を時系列ツリーで管理）

## 担当
- TAKUYA：運営、会場確認・交渉、リハスタ、公式LINE
- Kenichi：デザイン、アイコン・素材
- Yutaka：同期関係

Webアプリは `index.html` で動作します。
